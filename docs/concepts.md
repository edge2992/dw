# dw の考え方

用語は [GLOSSARY.md](../GLOSSARY.md) にまとめている。

## 作る → 書く → 見つける → 再開する

考えたいことを思いついたら、その場でトピックを一つ作る。作るときに聞かれるのは名前だけで、分類・状態・期限は聞かれない。そのまま書き始めてもいいし、何も書かずに置いておいてもいい。後で名前の一部で探して開き、同じ場所で続きを考える。

一時的なメモと長く続くプロジェクトを区別しない。メモが育っても、移行や「プロジェクトへの昇格」をする必要はない。

## 1 トピック = 1 ディレクトリ

```text
<root>/
└── 2026-10-24-調べ方を設計する/
    └── 調べ方を設計する.md      # メインノート
```

- ディレクトリ名は `<作成日>-<トピック名>`。日付は作った日を表し、一覧の並び順にも使う。
- メインノートのファイル名はトピック名と同じにする。Obsidian ではノートをファイル名で探したりリンクしたりするので、`README.md` や `STATE.md` のように全トピック共通の名前にすると、どのトピックのノートか見分けられない。
- トピック名は入力されたまま使う。日本語も空白も使える。ただし連続した空白（全角を含む）は半角 1 つにまとめる。一覧では見分けられない別トピックができるのを防ぐためだ。パスや Obsidian のリンクを壊す文字が入っていたら、黙って書き換えずに、その文字を示してエラーにする。
- ルートの中ではトピック名が重ならない。既にある名前を入力すると、新しく作らずにそのトピックを開く。名前の比較では大文字小文字、空白、`-`、`_` の違いを無視する。旧版で作った `datadog-cost` に `Datadog Cost` と打っても、別のトピックはできない。
- dw が作るのはメインノートの `# トピック名` の 1 行だけ。`logs/`、`sources/`、追加の Markdown などは、必要になったときに自分で置く。dw はそれらの名前や有無を気にしない。
- トピックが育ってファイルが増えたら、メインノートをそれらへの索引にすると見つけやすい。旧版の `STATE.md` だけのトピックや手作りのトピックも、`<トピック名>.md` を自分で置けばそれがメインノートになる。

## 探すつもりが作ってしまわないように

`dw <名前>` は、名前が完全一致すればそのトピックを、部分一致すれば候補を返し、どれにも当たらないときだけ作る。作ったときは必ず `dw: created <path>` と表示するので、検索のつもりの入力がトピックになっても気づける。

逆に、既存の名前の一部になる名前（`アーキ定例 10-28` があるときの `アーキ定例`）や、同じ名前で再発した障害には、部分一致が先に当たってしまう。そういうときはピッカーで `ctrl-o`、またはシェルで `dw new <名前>` を使う。部分一致を飛ばして作る。完全一致だけはそのトピックを開くので、名前が重ならないことは変わらない。

## filesystem が正本

一覧はルート直下のディレクトリをそのまま読んで作る。台帳もデータベースも持たない。Obsidian や `mkdir` で手作りしたディレクトリも、次に一覧を出したときに現れる。日付の付いていないディレクトリ（`読書を続ける/` など）は一覧の末尾に並ぶ。

dw が自分で持っている情報は「最近開いたトピック」5 件のパスだけで、これはキャッシュにすぎない。一覧の先頭に並べるために使う。1 件だけだと、毎日戻る長期トピックが、その日に作った短いトピックの下に沈んでしまうからだ。消えても、指しているディレクトリがなくなっていても、困ることはない。

dw が書き込むのは、新しくトピックを作るときだけ。既にあるトピックに書き足したり、名前を変えたり、移動したりはしない。

## 道具は薄く

dw は名前をパスに解決して表示するだけの道具で、選ぶのは fzf、移動するのはシェル関数の役目。エディタも Obsidian も Claude Code も起動しない。トピックで `claude` を起動して壁打ちするときに、結論をメインノートへ書かせたいなら、ルートに自分で `CLAUDE.md` を置いて一言そう書く（README の「With Claude Code」）。dw はこのファイルを作らない。旧版の dw が作っていた root の `CLAUDE.md` は使われなくなっていたので、決めごとを置くかどうかは使う人に任せる。中身は普通のディレクトリと Markdown なので、Obsidian でもエディタでも `rg` でも Claude でも、同じものを扱える。

dw は思考法でもタスク管理でもない。考える型が必要になったら、メインノートに書けばいい。
