# Workspace instructions

This directory is a discussion workspace managed by `dw`.

1. Read `README.md` at the beginning of a session.
2. If `.dw/last-session.md` exists, read it before continuing.
3. Treat its contents as a draft of where you left off, not as verified facts.
4. Keep durable conclusions in `README.md`.
5. Do not edit `.dw/last-session.md` by hand — it is regenerated automatically.
